# Criterios de rotacion de productos TW Store

Estos criterios ayudan a decidir que productos mantener, priorizar o retirar del catalogo y de las campanas semanales.

## Mantener productos

- Mantener si genera consultas por WhatsApp.
- Mantener si tiene margen aceptable para cubrir gestion, comunicacion, coordinacion y riesgo de variacion de precio.
- Mantener si tiene imagen atractiva o buen potencial visual para flyers, TikTok, Reels, Shorts y estados de WhatsApp.
- Mantener si tiene utilidad clara para estudiantes, gamers, profesionales o creadores de contenido.
- Mantener si el proveedor muestra disponibilidad recurrente o reposicion frecuente.
- Mantener si permite explicar beneficios de forma simple y comercial.

## Priorizar productos

- Priorizar si sirve para estudiantes, gamers, profesionales o creadores.
- Priorizar si combina precio competitivo y alto deseo visual.
- Priorizar si puede funcionar como producto bandera de la semana.
- Priorizar si permite armar combos o ventas complementarias.
- Priorizar si tiene buena relacion entre ticket, margen y facilidad de gestion.
- Priorizar si ayuda a posicionar TW Store como tienda tecnologica confiable y moderna.

## Retirar productos

- Retirar si no genera consultas en 30 dias.
- Retirar si sube demasiado de precio y pierde atractivo comercial.
- Retirar si no tiene stock recurrente o exige demasiadas verificaciones.
- Retirar si exige demasiada gestion para bajo margen.
- Retirar si cambia de especificaciones con frecuencia y puede generar confusion.
- Retirar si el proveedor deja de mostrar informacion clara de precio, garantia o entrega.

## Revision semanal

Cada semana revisar:

- Consultas recibidas por WhatsApp.
- Productos mas preguntados.
- Productos sin consultas.
- Variacion de precio del proveedor.
- Disponibilidad estimada.
- Margen final luego de costos y gestion.
- Calidad visual del producto para campanas.

## Semaforo comercial

**Verde:** producto con consultas, margen aceptable, visual atractivo y disponibilidad recurrente.  
**Amarillo:** producto interesante, pero requiere confirmar precio, stock o margen antes de publicar.  
**Rojo:** producto sin consultas, precio inestable, baja disponibilidad o demasiada gestion para poco margen.
