# Politica comercial de TW Store

TW Store es una linea comercial de e-commerce tecnologico de Tecprog World. Opera como catalogo tecnologico bajo pedido y dropshipping manual: el cliente consulta por WhatsApp, luego se confirma precio, stock, garantia y condiciones de entrega antes de continuar con la compra.

## Modelo comercial

- TW Store muestra productos tecnologicos de interes comercial para cotizacion manual.
- No procesa pagos en linea desde GitHub Pages.
- Cada solicitud debe validarse por WhatsApp antes de comprometer precio, stock, garantia o entrega.
- El catalogo puede incluir productos de proveedores externos, tiendas publicas o fuentes de referencia.

## Precios

- Los precios estan sujetos a confirmacion.
- Un precio publicado en TW Store debe entenderse como referencial hasta ser validado con la fuente correspondiente.
- Si el proveedor cambia el precio, TW Store debe informar al cliente antes de cerrar la cotizacion.
- No se debe mantener una oferta visible si el precio fuente ya no permite margen razonable.

## Stock y disponibilidad

- El stock esta sujeto a disponibilidad del proveedor.
- No se debe prometer stock inmediato si el producto depende de una tienda externa.
- Si el producto aparece como bajo pedido o stock por confirmar, debe comunicarse claramente al cliente.
- Si no hay stock, se puede ofrecer una alternativa similar, sin presionar la compra.

## Garantia

- La garantia se confirma antes de la compra.
- No se debe prometer una garantia especifica si no fue validada con el proveedor.
- Si el proveedor informa condiciones especiales, estas deben comunicarse de forma clara y por escrito al cliente.

## Entrega

- La entrega en Lima o provincias se coordina antes del pago.
- Para provincias puede considerarse Shalom u otro operador logistico disponible.
- Antes de coordinar despacho se debe confirmar direccion, datos de contacto, costo de envio, plazo estimado y condiciones de recojo o entrega.
- No se debe prometer fecha exacta de entrega sin confirmacion logistica.

## Representacion y marcas

- No se debe afirmar que Tecprog World es distribuidor oficial si no existe convenio formal.
- No se debe usar lenguaje que sugiera representacion oficial de marcas externas sin autorizacion verificable.
- Las marcas de productos pertenecen a sus respectivos titulares.

## Contenido de terceros

- No se deben copiar textos comerciales extensos de terceros.
- No se deben descargar ni reutilizar imagenes protegidas sin permiso.
- Se permite usar informacion tecnica minima y referencias publicas para orientar la cotizacion, siempre con redaccion propia.

## Frase comercial recomendada

Producto sujeto a disponibilidad, confirmacion de precio, garantia y condiciones de entrega.
