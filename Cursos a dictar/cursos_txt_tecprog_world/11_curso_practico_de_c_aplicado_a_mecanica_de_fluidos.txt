TÍTULO COMERCIAL
Curso práctico de C++ aplicado a Mecánica de Fluidos

DESCRIPCIÓN CORTA
Programa métodos numéricos y construye tu primer mini-solver para problemas de fluidos.

PÚBLICO OBJETIVO
Estudiantes, tesistas, programadores científicos y profesionales interesados en CFD, modelación numérica y software técnico.

TECNOLOGÍAS Y HERRAMIENTAS
- C++
- Visual Studio 2022
- VS Code
- Métodos numéricos
- CSV/TXT
- Python para gráficos
- Programación científica

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Usar C++ moderno para programación científica.
2. Representar mallas, campos y variables físicas.
3. Implementar esquemas de advección, difusión y estabilidad.
4. Construir un mini-solver con exportación y visualización de resultados.

PROYECTO FINAL
Mini-solver C++ para transporte 1D de una variable física con exportación CSV y análisis gráfico.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: C++ moderno para ingeniería.
- Sesión 2: Mallas, campos y archivos de datos.
- Sesión 3: Advección, difusión y estabilidad.
- Sesión 4: Mini-solver y proyecto final.
