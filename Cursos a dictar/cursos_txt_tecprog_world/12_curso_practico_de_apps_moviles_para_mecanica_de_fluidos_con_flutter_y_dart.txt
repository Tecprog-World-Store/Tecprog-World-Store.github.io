TÍTULO COMERCIAL
Curso práctico de Apps Móviles para Mecánica de Fluidos con Flutter y Dart

DESCRIPCIÓN CORTA
Crea aplicaciones Android para cálculos técnicos de Reynolds, caudal, velocidad y pérdida de carga.

PÚBLICO OBJETIVO
Estudiantes, docentes, profesionales y desarrolladores que desean crear apps técnicas para ingeniería.

TECNOLOGÍAS Y HERRAMIENTAS
- Flutter
- Dart
- Android Studio
- VS Code
- Android
- Firebase opcional
- Git

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Crear interfaces móviles con Flutter y Dart.
2. Diseñar formularios técnicos con validación de datos.
3. Implementar cálculos de mecánica de fluidos.
4. Generar un APK instalable para Android.

PROYECTO FINAL
FluidCalc Mobile, una app Android para cálculos de Reynolds, caudal, velocidad y pérdida de carga.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Flutter, Dart y primera app Android.
- Sesión 2: Formularios y cálculos de mecánica de fluidos.
- Sesión 3: Diseño, resultados, gráficos e historial.
- Sesión 4: APK, instalación en Android y proyecto final.
