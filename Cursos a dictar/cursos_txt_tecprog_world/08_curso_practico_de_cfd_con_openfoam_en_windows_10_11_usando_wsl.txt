TÍTULO COMERCIAL
Curso práctico de CFD con OpenFOAM en Windows 10/11 usando WSL

DESCRIPCIÓN CORTA
Instala OpenFOAM en Windows con WSL, ejecuta casos CFD y postprocesa resultados en ParaView.

PÚBLICO OBJETIVO
Estudiantes y profesionales de ingeniería mecánica de fluidos, mecánica, civil, ambiental, hidráulica, energía y simulación.

TECNOLOGÍAS Y HERRAMIENTAS
- Windows 10/11
- WSL2
- Ubuntu
- OpenFOAM
- ParaView
- VS Code
- Linux Shell
- Python opcional

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Instalar y configurar WSL2, Ubuntu, OpenFOAM y ParaView.
2. Comprender la estructura de casos OpenFOAM.
3. Modificar malla, condiciones de frontera y parámetros numéricos.
4. Ejecutar un caso CFD y visualizar velocidad, presión y líneas de corriente.

PROYECTO FINAL
Simulación CFD de flujo alrededor de un cilindro 2D usando OpenFOAM y ParaView.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Instalación del entorno CFD.
- Sesión 2: Primer caso CFD y estructura OpenFOAM.
- Sesión 3: Malla, condiciones de frontera y solver.
- Sesión 4: Postproceso y proyecto final.
