TÍTULO COMERCIAL
Curso práctico de Machine Learning aplicado a Mecánica de Fluidos

DESCRIPCIÓN CORTA
Predice, analiza y optimiza datos CFD, experimentales e hidrológicos con Python.

PÚBLICO OBJETIVO
Estudiantes, tesistas, investigadores y profesionales de mecánica de fluidos, hidráulica, CFD, hidrología y ciencia de datos aplicada.

TECNOLOGÍAS Y HERRAMIENTAS
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter
- OpenFOAM como contexto
- Google Colab

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Preparar datasets técnicos de fluidos.
2. Entrenar modelos de machine learning para predecir variables físicas.
3. Evaluar modelos con métricas como RMSE, MAE y R².
4. Construir modelos sustitutos para aproximar resultados de simulaciones o experimentos.

PROYECTO FINAL
Modelo predictivo aplicado a una variable de mecánica de fluidos con gráficos, métricas e interpretación técnica.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Datos de fluidos y Python científico.
- Sesión 2: Modelos supervisados para predicción.
- Sesión 3: Modelos sustitutos y reducción de orden.
- Sesión 4: Proyecto final aplicado.
