TÍTULO COMERCIAL
Curso práctico de Cloud Computing para OpenFOAM

DESCRIPCIÓN CORTA
Ejecuta CFD en la nube con AWS/Azure, escala tus casos y controla costos computacionales.

PÚBLICO OBJETIVO
Usuarios de OpenFOAM, estudiantes avanzados, profesionales CFD, investigadores y consultores que requieren mayor capacidad de cómputo.

TECNOLOGÍAS Y HERRAMIENTAS
- OpenFOAM
- AWS EC2
- Azure VM
- Ubuntu
- SSH
- OpenMPI
- ParaView
- Cloud Computing

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Entender costos, seguridad y arquitectura cloud para CFD.
2. Lanzar una instancia cloud y ejecutar OpenFOAM.
3. Aplicar paralelización con decomposePar, mpirun y reconstructPar.
4. Transferir resultados, postprocesar y estimar costo-rendimiento.

PROYECTO FINAL
Simulación CFD paralela de flujo alrededor de un cilindro 2D ejecutada en infraestructura cloud.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Fundamentos de Cloud CFD, costos y seguridad.
- Sesión 2: OpenFOAM en la nube y acceso remoto.
- Sesión 3: Simulaciones paralelas, monitoreo y transferencia de datos.
- Sesión 4: Proyecto final y control de costos.
