TÍTULO COMERCIAL
Curso práctico de Geoportales Web GIS con Python y GeoServer

DESCRIPCIÓN CORTA
Publica capas, crea visores interactivos y habilita descarga de datos para usuarios finales.

PÚBLICO OBJETIVO
Profesionales GIS, consultores, municipalidades, estudiantes, investigadores, catastro, ambiente, hidrología e infraestructura.

TECNOLOGÍAS Y HERRAMIENTAS
- QGIS
- PostGIS
- GeoServer
- Python
- Leaflet
- HTML
- CSS
- JavaScript

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Entender la arquitectura Web GIS open-source.
2. Publicar capas espaciales con GeoServer y PostGIS.
3. Crear un visor web interactivo con control de capas y popups.
4. Implementar descargas de datos mediante un backend Python.

PROYECTO FINAL
Geoportal Web GIS con capas publicadas, visor interactivo, consulta de atributos y descarga de datos.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Arquitectura Web GIS, servicios OGC y flujo de datos.
- Sesión 2: PostGIS + GeoServer y publicación de capas.
- Sesión 3: Visor web con Leaflet, popups y control de capas.
- Sesión 4: Backend Python, descargas y proyecto final.
