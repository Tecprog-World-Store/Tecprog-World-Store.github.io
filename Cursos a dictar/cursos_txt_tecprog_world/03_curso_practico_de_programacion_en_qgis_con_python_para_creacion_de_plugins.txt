TÍTULO COMERCIAL
Curso práctico de Programación en QGIS con Python para creación de plugins

DESCRIPCIÓN CORTA
Crea tu primer plugin para QGIS, diseña interfaces con Qt Designer y automatiza geoprocesos con PyQGIS.

PÚBLICO OBJETIVO
Estudiantes, tesistas y profesionales GIS, ambientales, civiles, geógrafos, hidrólogos, consultores y usuarios de QGIS.

TECNOLOGÍAS Y HERRAMIENTAS
- QGIS
- Python
- PyQGIS
- PyQt
- Qt Designer
- Processing Toolbox
- GeoPackage

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Usar la consola Python de QGIS y acceder a capas, atributos y geometrías.
2. Automatizar geoprocesos con PyQGIS.
3. Diseñar interfaces gráficas con Qt Designer y PyQt.
4. Empaquetar un plugin funcional para QGIS.

PROYECTO FINAL
Plugin GIS que procesa una capa, ejecuta un geoproceso, muestra resultados y exporta información.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Fundamentos de PyQGIS, capas y atributos.
- Sesión 2: Geoprocesamiento y automatización con Processing.
- Sesión 3: Interfaces con Qt Designer y PyQt.
- Sesión 4: Plugin final, empaquetado y presentación.
