TÍTULO COMERCIAL
Curso práctico de Programación para AutoCAD con C# y Visual Studio

DESCRIPCIÓN CORTA
Crea comandos personalizados, automatiza tareas repetitivas y desarrolla tu primer plugin cargable con NETLOAD.

PÚBLICO OBJETIVO
Estudiantes y profesionales de ingeniería, arquitectura, topografía, CAD/BIM y desarrollo de software técnico.

TECNOLOGÍAS Y HERRAMIENTAS
- AutoCAD
- .NET API
- C#
- Visual Studio 2022
- DLL
- NETLOAD
- CSV

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Crear un proyecto C# compatible con AutoCAD.
2. Programar comandos personalizados mediante la API .NET de AutoCAD.
3. Automatizar entidades, bloques, capas, textos y datos del dibujo.
4. Compilar una DLL y cargarla en AutoCAD con NETLOAD.

PROYECTO FINAL
Plugin para AutoCAD que ejecuta comandos personalizados, automatiza una tarea CAD y genera una salida técnica.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Entorno AutoCAD + Visual Studio y primer comando C#.
- Sesión 2: Creación y modificación de entidades DWG desde código.
- Sesión 3: Automatización de bloques, atributos y exportación de datos.
- Sesión 4: Plugin final, carga con NETLOAD y presentación.
