TÍTULO COMERCIAL
Curso práctico de Software de IA Offline con Python, Ollama y PySide

DESCRIPCIÓN CORTA
Crea tu propio chat local con IA, sin tokens, sin dependencia de la nube y con interfaz de escritorio.

PÚBLICO OBJETIVO
Estudiantes, programadores, docentes, investigadores, profesionales y emprendedores que desean construir software de IA local.

TECNOLOGÍAS Y HERRAMIENTAS
- Python
- Ollama
- PySide
- Qt
- API REST local
- Modelos IA locales
- PyInstaller

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Instalar Ollama y descargar modelos de IA locales.
2. Conectar Python con la API local de Ollama.
3. Crear una interfaz gráfica tipo chat con PySide.
4. Gestionar historial, selección de modelo y exportación de conversación.

PROYECTO FINAL
Aplicación de escritorio tipo chat offline conectada a modelos locales con Ollama.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: Instalación de Ollama, modelos locales y pruebas desde terminal.
- Sesión 2: Backend Python para consumir la API local de Ollama.
- Sesión 3: Interfaz gráfica con PySide y experiencia de usuario.
- Sesión 4: Chat offline final, exportación y empaquetado básico.
