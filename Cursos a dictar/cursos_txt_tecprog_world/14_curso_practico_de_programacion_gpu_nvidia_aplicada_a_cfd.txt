TÍTULO COMERCIAL
Curso práctico de Programación GPU NVIDIA aplicada a CFD

DESCRIPCIÓN CORTA
Acelera cálculos de mecánica de fluidos con CUDA C++, librerías científicas y mini-solvers numéricos.

PÚBLICO OBJETIVO
Estudiantes avanzados, programadores científicos, usuarios CFD, investigadores y profesionales con interés en HPC y aceleración GPU.

TECNOLOGÍAS Y HERRAMIENTAS
- CUDA C++
- NVIDIA GPU
- Visual Studio 2022
- VS Code
- PETSc
- AmgX
- cuBLAS
- cuSPARSE
- Python para visualización

¿QUÉ APRENDERÁ EL PARTICIPANTE?
1. Entender arquitectura GPU, threads, blocks y grids.
2. Compilar programas CUDA C++ con nvcc.
3. Acelerar operaciones científicas y campos 1D/2D.
4. Implementar un mini-solver CFD y comparar CPU vs GPU.

PROYECTO FINAL
Mini-solver GPU en CUDA C++ para difusión/advección 2D con comparación CPU vs GPU y visualización de resultados.

TEMARIO / CRONOGRAMA ACADÉMICO
- Sesión 1: CUDA C++ y arquitectura GPU.
- Sesión 2: Memoria, kernels y campos numéricos.
- Sesión 3: Stencils, difusión/advección y residuales.
- Sesión 4: Mini-solver GPU y panorama PETSc/AmgX/OpenFOAM.
