# Checklist de publicacion

Usa esta lista antes de publicar cambios en GitHub Pages.

## Contenido

- [ ] Revisar que cada pagina tenga titulo claro.
- [ ] Revisar meta description en paginas principales.
- [ ] Revisar que no existan textos de prueba, TODO, lorem ipsum o placeholders visibles.
- [ ] Revisar que no haya mojibake: `Ã`, `Â`, `�`.
- [ ] Revisar que los nombres de lineas de negocio sean canonicos.

## Enlaces

- [ ] Revisar enlaces internos.
- [ ] Revisar enlaces externos.
- [ ] Revisar enlaces a detalle: cursos, servicios, productos, guias y ofertas.
- [ ] Revisar enlaces de retorno a catalogos y lineas.
- [ ] Revisar mapa del sitio.

## Precios

- [ ] Revisar precios en soles.
- [ ] Revisar precios en USD.
- [ ] Usar "Desde S/ ..." y "Desde USD ..." cuando el alcance varie.
- [ ] Revisar politica MOOC de TW Educa.
- [ ] Confirmar que lo gratuito no parezca incluir certificado completo.

## WhatsApp

- [ ] Revisar que los botones de WhatsApp abran `https://wa.me/51952354282`.
- [ ] Revisar que el mensaje sea especifico para la oferta.
- [ ] Revisar CTA de cotizacion en paginas comerciales.
- [ ] Revisar CTA en paginas de detalle.

## Footer y navegacion

- [ ] Revisar menu superior.
- [ ] Revisar footer institucional.
- [ ] Revisar panel lateral derecho.
- [ ] Revisar boton flotante de WhatsApp.
- [ ] Revisar navegacion movil.

## PDF

- [ ] Revisar que los PDF existan en `assets/pdf/`.
- [ ] Revisar que el visor o enlace de descarga funcione.
- [ ] Revisar que solo se haya subido el PDF final.
- [ ] No subir auxiliares LaTeX.
- [ ] Revisar peso de PDF grandes.

## Imagenes

- [ ] Revisar logos.
- [ ] Revisar banners.
- [ ] Revisar miniaturas de cursos.
- [ ] Revisar imagenes de servicios y productos.
- [ ] Revisar que el QR de pago sea legible.
- [ ] Revisar rutas relativas desde subcarpetas.

## UTF-8

- [ ] Ejecutar `scripts\revisar_utf8.bat`.
- [ ] Corregir textos rotos.
- [ ] Confirmar que HTML tenga `<meta charset="UTF-8">`.
- [ ] Validar JSON despues de editar.

## Responsive

- [ ] Revisar escritorio.
- [ ] Revisar movil.
- [ ] Revisar tablets o ancho intermedio.
- [ ] Revisar que no se monten textos sobre botones.
- [ ] Revisar panel lateral y menu movil.

## Consola

- [ ] Abrir DevTools.
- [ ] Revisar errores JavaScript.
- [ ] Revisar errores 404 de imagenes, JSON, CSS, JS o PDF.
- [ ] Revisar advertencias importantes.

## Git

- [ ] Ejecutar `git status --short`.
- [ ] Revisar cambios antes de commit.
- [ ] Hacer commit con mensaje claro.
- [ ] Hacer push.
- [ ] Verificar despliegue en GitHub Pages.

## Prueba final

- [ ] Abrir `index.html`.
- [ ] Abrir una pagina de linea.
- [ ] Abrir un catalogo.
- [ ] Abrir un detalle.
- [ ] Abrir pagos Peru.
- [ ] Abrir pagos internacionales.
- [ ] Probar WhatsApp.
- [ ] Probar descarga/visor PDF.
