# Regla de precios TW Store

TW Store de Tecprog World se orienta a un mercado online internacional. Por ello, la moneda por defecto para nuevos productos debe ser USD.

Los productos pueden mostrar PEN u otra moneda solo si el JSON lo define explicitamente. Si un producto nuevo no define moneda, el sistema debe asumir USD.

No se deben convertir precios existentes automaticamente. Los productos que ya declaran PEN, USD u otra moneda deben conservar su moneda definida.

Los precios, disponibilidad, garantia y envio estan sujetos a confirmacion comercial por WhatsApp antes de cerrar cualquier operacion.

No todos los servicios deben tener precio fijo. Algunos productos, servicios, cursos o soluciones deben quedar como cotizacion cuando el alcance dependa de requerimientos, disponibilidad, modalidad, ubicacion o validacion tecnica.
