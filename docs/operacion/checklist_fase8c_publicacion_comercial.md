# Checklist Fase 8C - Publicación comercial

## Navegación

- [x] Las páginas de línea cargan desde sus rutas públicas.
- [x] El catálogo aparece como primera sección comercial.
- [x] Los enlaces internos principales se mantienen.

## Buscador

- [x] Buscador central visible arriba del panel central.
- [x] Búsqueda por línea limitada al catálogo correspondiente.
- [x] TW Store mantiene búsqueda global.

## Filtros

- [x] Panel izquierdo visible con búsqueda, categoría, moneda, estado, precio y ordenamiento.
- [x] Categorías filtradas por línea cuando aplica.

## Cards

- [x] Cards comerciales con imagen 1:1.
- [x] Botón WhatsApp visible.
- [x] Botón Ver detalle visible cuando existe URL.
- [x] Estado, precio o modalidad visibles según item.

## Imágenes

- [x] Imágenes de cards ocupan el contenedor superior.
- [x] `object-fit: cover` aplicado en cards.
- [x] Imágenes de detalle mantienen visualización completa.
- [x] Rutas de imágenes de cursos verificadas.

## Detalle

- [x] Detalle de producto TW Store probado.
- [x] Detalle de curso TW Educa probado.
- [x] Detalle de servicio de otra línea probado.

## WhatsApp

- [x] Enlaces WhatsApp renderizados en cards.
- [x] Acciones rápidas por línea incluyen WhatsApp.
- [x] No se envían mensajes automáticamente.

## Responsive

- [x] 390x844 sin overflow horizontal.
- [x] 768x1024 sin overflow horizontal.
- [x] 1366x768 sin overflow horizontal.

## SEO básico

- [x] `meta charset="UTF-8"` presente.
- [x] Titles y meta descriptions conservados.
- [x] Detalles de cursos mantienen metas dinámicas.

## Ausencia de datos internos

- [x] Sin campos visibles `proveedor`, `margen`, `url_fuente` o equivalentes en vistas públicas probadas.
- [x] No se alteraron precios.
- [x] No se borraron cursos ni productos.
