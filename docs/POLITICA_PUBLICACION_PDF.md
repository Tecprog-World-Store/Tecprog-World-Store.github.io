# Politica de publicacion de PDF para Tecprog World

Los PDF finales publicos van en:

```text
assets/pdf/guias/
assets/pdf/compendios/
assets/pdf/catalogos/
assets/pdf/brochures/
```

Los archivos fuente LaTeX van fuera del repositorio web:

```text
D:\DiskE01\Organizacionies\E-TW\Produccion_LaTeX_TW
```

No subir auxiliares:

```text
.aux
.log
.out
.toc
.synctex.gz
.fls
.fdb_latexmk
```

No subir libros ni papers completos con copyright.

No subir PDFs pesados si pueden optimizarse. Evitar que `assets/pdf/` supere demasiado peso y revisar el tamano del repositorio antes de publicar.

Usar nombres sin espacios, sin tildes y en minusculas.

Ejemplo:

```text
guia-openshot-linux-mint-ffmpeg.pdf
```
