# Checklist Antes De Modificar

Antes de cambios estructurales:

- Leer todos los archivos de `docs/restricciones_codex/`.
- Comparar la solicitud con `ARQUITECTURA_APROBADA.md`.
- Verificar si el cambio toca archivos criticos.
- Crear backup antes de cambios estructurales.
- Ejecutar validaciones de no regresion.
- Detenerse si la tarea contradice una regla protegida.
- Documentar la excepcion si el usuario pide explicitamente romper una restriccion previa.
- Mantener compatibilidad con GitHub Pages.
- Mantener SEO, Open Graph y mensajes comerciales aprobados.
- No hacer commit ni push salvo instruccion explicita.
