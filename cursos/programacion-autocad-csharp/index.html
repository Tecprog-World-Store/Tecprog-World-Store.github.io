Extiende AutoCAD con tus propias herramientas

Del código básico a un producto instalable

Aprende a crear plugins que calculan, dibujan, procesan datos y automatizan flujos de trabajo. No se aprende solamente a ejecutar comandos: se aprende a construir software que extiende AutoCAD.

Innovación aplicada

Convierte procesos repetitivos en herramientas CAD mantenibles para ingeniería y producción.

Interfaces profesionales

Integra ventanas WPF, paneles PaletteSet y una pestaña Ribbon con una experiencia clara.

Ingeniería y geometría

Relaciona parámetros, cálculos y datos con resultados visibles en 2D y 3D.

Distribución real

Pasa de la DLL de desarrollo a bundle, autoload, instalador y flujo de activación de referencia.

18 módulos + proyecto final

Temario práctico y progresivo

Fácil → intermedio → GUI → integración → ingeniería → producto distribuible. Abre cada módulo para revisar el contenido.

Módulo 01 · Entorno de desarrollo
  • Arquitectura de un plugin .NET, C#, Visual Studio 2026 y AutoCAD 2027.
  • Class Library, referencias de AutoCAD .NET API, estructura del proyecto y Debug/Release.
  • NETLOAD para desarrollo frente a instalación y autoload.

Proyecto: primer plugin funcional.

Módulo 02 · Primeros comandos
  • CommandMethod y ejercicios con información del dibujo, puntos, líneas, círculos, arcos y polilíneas.
  • Texto, áreas, pendientes y edición o eliminación de objetos.

Proyecto: colección inicial de comandos personalizados.

Módulo 03 · Database y Transactions
  • Document, Database, Editor, Transaction, BlockTable y BlockTableRecord.
  • Model Space, entidades, lectura y escritura segura, y manejo de errores.

Proyecto: generador paramétrico de geometría.

Módulo 04 · Selección y manipulación
  • PromptEntityOptions, SelectionSet, filtros y selección múltiple.
  • Propiedades, layers, colores y tipos de línea.

Proyecto: herramientas de edición automatizada.

Módulo 05 · Layers, Blocks y atributos
  • Creación y administración de layers.
  • Bloques, inserción, atributos y reutilización de componentes CAD.

Proyecto: biblioteca técnica reutilizable.

Módulo 06 · Anotaciones y tablas
  • DBText, MText, dimensiones, etiquetas y tablas.
  • Reportes e información técnica automatizada sobre el drawing.

Proyecto: plano anotado automáticamente.

Módulo 07 · Interfaces GUI con WPF
  • Ventanas, formularios, inputs, ComboBox, botones y valores predeterminados.
  • Validación, resultados, organización de controles y experiencia del usuario.

Proyecto: calculadora técnica integrada con AutoCAD.

Módulo 08 · PaletteSet profesional
  • PaletteSet modeless y comunicación GUI ↔ AutoCAD.
  • Navegación por módulos, estado compartido y arquitectura reusable.

Proyecto: panel profesional de herramientas.

Módulo 09 · Ribbon personalizado
  • Ribbon Tab, panels, botones, comandos e iconos.
  • Conexión con PaletteSet y branding técnico.

Proyecto: pestaña completa integrada en AutoCAD.

Módulo 10 · Datos y archivos
  • Lectura y escritura de TXT, CSV y JSON.
  • Importación, exportación, configuración persistente y proyectos editables.

Proyecto: herramienta CAD basada en datos externos.

Módulo 11 · Geometría 2D
  • Perfiles, secciones, plantas y anotaciones calculadas desde C#.
  • Escalas y layers según el tipo de resultado.

Proyecto: generador automático de vistas técnicas.

Módulo 12 · AutoCAD 3D desde .NET
  • Point3d, Vector3d, Polyline3d, regiones, extrusión y geometría paramétrica.
  • Superficies y sólidos cuando corresponda, orientación espacial y vista isométrica.
  • Generación de FRONT, TOP, SIDE e ISOMETRIC.

Proyecto: objeto técnico tridimensional editable.

Módulo 13 · Automatización para ingeniería
  • Ejemplos originales con fórmulas, unidades, parámetros y cálculo numérico.
  • Relación entre resultados matemáticos y geometría dibujada.

Enfoque: aplicaciones diversas, no limitadas a una sola especialidad.

Módulo 14 · Caso Water Engineering Suite
  • Caso didáctico de referencia: Open Channel Designer, Pipe Hydraulics, Hydrology y Wave Designer.
  • Integración conceptual de CALCULATE, DRAW 2D, CREATE 3D, GENERATE VIEWS, ANNOTATE, IMPORT y EXPORT.

Solo se presentan capacidades verificadas del prototipo de referencia.

Módulo 15 · Arquitectura profesional
  • Separación Core / AutoCAD UI, servicios, commands y ViewModels.
  • Reutilización, estado, configuración y estructura mantenible.

Proyecto: refactor del plugin hacia una arquitectura profesional.

Módulo 16 · Distribución
  • Release x64, ApplicationPlugins, .bundle, PackageContents.xml, autoload y compatibilidad.
  • Flujo: CODE → BUILD → CLOSE AUTOCAD → INSTALL → START AUTOCAD → AUTOLOAD.

Proyecto: bundle instalable y actualizable.

Módulo 17 · Instalador Windows
  • Empaquetado, instalación, desinstalación y actualización.
  • Inno Setup o herramienta vigente, assets, iconos y versionado.

Proyecto: Setup.exe funcional.

Módulo 18 · Licenciamiento y comercialización
  • Machine ID, licencia, activación, trial, firma y validación.
  • Protección razonable, distribución, mantenimiento y versiones, sin prometer antipiratería absoluta.

Proyecto: flujo de activación de referencia.
