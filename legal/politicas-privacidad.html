Políticas de Privacidad

Esta política describe el tratamiento inicial de datos personales en el sitio web estático de Tecprog World E.I.R.L.

Datos solicitados

El sitio puede mostrar enlaces a WhatsApp, correo electrónico, PayPal, redes sociales y un formulario visual de Libro de Reclamaciones. Esta versión no almacena información en una base de datos propia.

Canales externos

Al usar WhatsApp, PayPal, correo o redes sociales, el usuario interactúa con plataformas externas sujetas a sus propias políticas de privacidad y términos de uso.

Finalidad

Los datos compartidos por el usuario se usan para responder consultas, preparar cotizaciones, coordinar compras, brindar soporte o atender solicitudes comerciales y legales.

Seguridad

Antes de operar formularios reales, Tecprog World E.I.R.L. debe conectar mecanismos seguros de recepción, almacenamiento y gestión de datos.

Contacto

Para ejercer consultas relacionadas con privacidad, escribe a grupotecprog@gmail.com.
