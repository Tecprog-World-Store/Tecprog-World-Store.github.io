Manual de usuario — CORVUS AI v4

Guía de la versión 4.0.0-alpha. El instalador todavía no está disponible públicamente.

Volver a la ficha

1. Qué instala esta versión

CORVUS v4 es un agente local de productividad con interfaz gráfica en español, modo Guiado y modo Avanzado. El instalador copia la aplicación, configuración, logo, manual y accesos directos. La versión alfa actual requiere Python 3.11 o posterior instalado en Windows.

Ollama y los modelos no forman parte del instalador: son componentes externos con tamaño, actualización y licencias propias.

2. Requisitos

  • Windows 10/11 de 64 bits.
  • Python 3.11 o posterior, con Tkinter.
  • Para IA local: Ollama activo en http://127.0.0.1:11434.
  • 8 GB de RAM como mínimo para texto pequeño; 12–16 GB recomendados para visión de 4B.
  • 1 GB libre para CORVUS y temporales, más el tamaño de cada modelo.

En un Intel Core i5-1035G1, 11.6 GB de RAM y NVIDIA MX330 de 2 GB, qwen3.5:4b funciona con visión, pero casi todo el cálculo recae en CPU. Una respuesta visual breve tardó 95 segundos; no se promete respuesta interactiva rápida en ese hardware.

3. Instalar CORVUS

  1. Ejecuta CORVUS_v4_Instalador_4.0.0-alpha.exe solo cuando se publique desde un canal autorizado.
  2. El asistente está en español y no requiere privilegios administrativos.
  3. Opcionalmente, crea el acceso directo del escritorio.
  4. Abre CORVUS v4 desde Inicio.

Si falta Python, instala Python 3.11+ desde su fuente oficial, incluye python en PATH y vuelve a ejecutar el instalador. Esta edición no incluye un runtime independiente.

4. Instalar Ollama y el modelo

  1. Instala Ollama para Windows desde su sitio oficial y abre el servicio.
  2. En una terminal ejecuta ollama pull qwen3.5:4b.
  3. Comprueba con ollama list que aparece qwen3.5:4b.
  4. En config/corvus.toml, configura text = "qwen3.5:4b" y vision = "qwen3.5:4b".
  5. Abre CORVUS y comprueba que Texto y Visión figuren disponibles.

La descarga del modelo ronda 3.4 GB. CORVUS no la inicia automáticamente; el usuario controla la descarga y debe revisar la licencia del modelo.

5. Uso

En Modo Guiado, escribe una solicitud, elige un artefacto como resultados/informe.md y pulsa Crear resultado. Puedes adjuntar texto o una fotografía PNG/JPEG. Con una imagen, CORVUS utiliza el modelo de visión para describir escenas y razonar sobre ellas; no se limita a OCR.

Usa Cambiar carpeta… para elegir o crear el proyecto activo. Cada proyecto guarda conversaciones separadas en .corvus/conversations. El estado combina texto y color: verde significa LISTO; ámbar, EN PROCESO; rojo, ATENCIÓN. El Modo Avanzado permite solicitar supuestos, variables y criterios de verificación.

6. Privacidad y límites

Los archivos se escriben dentro del espacio de trabajo y no se sobrescriben por defecto. La ejecución de scripts permanece deshabilitada. Los modelos pueden equivocarse: revisa cálculos, decisiones de ingeniería y material profesional.

CORVUS puede crear fuentes Python, C, C++, C#, Fortran y R, además de archivos de proyecto y documentación. Esto no instala ni ejecuta compiladores. Audio aún no está integrado.

7. Solución de problemas

  • Ollama no responde: abre Ollama y vuelve a iniciar CORVUS.
  • Visión no disponible: confirma ollama list y que models.vision coincide exactamente.
  • Respuesta lenta: cierra aplicaciones para liberar RAM y evita modelos mayores en equipos modestos.
  • El artefacto existe: elige otro nombre; CORVUS no sobrescribe por defecto.

8. Firma, hash y SmartScreen

El instalador alfa actual no tiene firma digital. Windows SmartScreen puede mostrar una advertencia y no se promete evitarla.

Para una futura descarga autorizada, verifica el hash con Get-FileHash .\CORVUS_v4_Instalador_4.0.0-alpha.exe -Algorithm SHA256 y el estado de firma con Get-AuthenticodeSignature .\CORVUS_v4_Instalador_4.0.0-alpha.exe.

SHA-256 actual: B0911629ECA6F2E8D6D242938617C4B248316553E5720DE8F5220BEFC339D6E2.

Si el archivo se firma o reconstruye, el hash cambiará. Una versión pública futura debería firmarse con Authenticode mediante un certificado válido o Microsoft Artifact Signing, usar sellado de tiempo e identidad editorial constante.
