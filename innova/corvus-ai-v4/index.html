CORVUS AI v4 alpha

Asistente local de productividad en español con texto y visión. Esta versión inicial es gratuita para posicionamiento y evaluación temprana.

Descarga externa aún no publicada Leer manual de usuario Consultar disponibilidad

Qué hace esta versión

  • Interfaz gráfica en español con modos Guiado y Avanzado.
  • Conversación local y creación de archivos dentro del proyecto elegido.
  • Análisis de texto e imágenes mediante un modelo local con capacidad de visión.
  • Historial separado por proyecto y contexto local limitado.

Alcance alfa

CORVUS v4 puede contener errores, depender del rendimiento del equipo y producir respuestas incorrectas. Los resultados técnicos, cálculos y decisiones profesionales deben revisarse antes de usarse.

La ejecución de scripts permanece deshabilitada. Audio aún no está integrado.

Antes de instalar

Requisitos y componentes no incluidos

Windows

Windows 10 u 11 de 64 bits.

Python

Python 3.11 o posterior con Tkinter. Esta versión alfa no incluye un runtime independiente.

Ollama

Ollama debe instalarse y estar activo por separado en el equipo.

Modelo local

El modelo de texto/visión no está incluido. El usuario controla su descarga y debe revisar su licencia.

Memoria

8 GB de RAM como mínimo para modelos pequeños de texto; 12–16 GB recomendados para visión de 4B.

Almacenamiento

1 GB para CORVUS y temporales, más el espacio que ocupe cada modelo local.

Estado de disponibilidad

Descarga gratuita: pendiente de publicación externa

Existe un instalador alfa local, pero todavía no hay una URL pública autorizada. Por eso esta página no enlaza a un archivo inexistente ni aloja el binario en GitHub Pages.

Cuando se autorice el canal externo, este bloque se actualizará con el nombre exacto del archivo, su origen y una descarga verificable.

Instalador sin firma digital

El instalador alfa actual no tiene firma Authenticode. Windows SmartScreen puede mostrar una advertencia, especialmente durante las primeras descargas. No se promete evitarla ni se indican métodos para eludirla.

Verificación recomendada

Antes de ejecutar una futura descarga autorizada, verifica el origen HTTPS, el nombre del archivo y el SHA-256 publicado. Una versión posterior debería firmarse con certificado válido y sellado de tiempo antes de distribuirse ampliamente.

Evolución del producto

Gratis ahora; posible edición de pago más adelante

La versión alfa se plantea gratuita para dar a conocer CORVUS y recoger experiencia de uso. Se contempla una futura versión de pago, pero todavía no se anuncian fecha, precio, funciones exclusivas ni condiciones comerciales.
